Privacy Policy

Your files. Your control.

Data practices for Soltan Local Sync, a personal utility operated by Soltan Baghirli.

Last updated 2 November 2026

1. Scope

This policy describes the personal desktop synchronization utility and this information website. The utility is used by its operator to synchronize selected local folders with an account the operator authorizes in Google Drive.

2. Data accessed and why

To identify and synchronize files, the utility accesses file contents and metadata such as names, folder paths, file identifiers, sizes, modification times and checksums. It uses Google OAuth credentials and tokens to authenticate access.

The requested Drive authorization permits broader access than the selected synchronization folders. Actual transfers are limited by the local configuration. Data is used for owner-directed synchronization, conflict handling, backup and troubleshooting. This desktop utility does not use Google API data for advertising, sale of personal data or model training.

3. Storage and transfers

Files are stored on the operator’s computer and in Google Drive. Configured backup copies can remain in separate local and Drive folders. Synchronization history and logs on the computer can contain filenames, paths, metadata and transfer results.

OAuth credentials and tokens are stored in the local rclone configuration and used to authenticate with Google. They are not included in this website. Access to the computer and configuration must be restricted by the operator.

Google processes data under its own Privacy Policy. This website is hosted separately on GitHub Pages and does not receive synchronized document contents.

4. Separately authorized integrations

The operator may separately authorize a service such as ChatGPT to access files in Google Drive. When that service is used, file content and metadata may be processed under that service’s terms and account settings. That authorization is separate from this desktop utility. Revoking one connection does not automatically revoke the other.

5. Retention and deletion

Files, backup versions and logs remain until the operator removes them or changes the configuration. The current pilot does not automatically prune its backup folders or logs. Synchronization can propagate a deletion between the selected folders while retaining a configured backup copy.

The operator can stop synchronization and revoke this application’s access through Google Account connections. Revoking access does not itself delete existing local files, Drive files, backups or logs. Those copies are managed separately by the operator.

6. Website visitors

This information website contains no application-added analytics, advertising, forms or tracking scripts. GitHub may process connection and usage information while hosting it, as described in the GitHub Privacy Statement.

7. Changes and contact

This policy will be updated when the utility’s data practices change. Questions about Soltan Local Sync can be sent to the operator at the contact address below.
