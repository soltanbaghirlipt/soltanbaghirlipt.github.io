Soltan Local Sync

Keep selected folders on a Windows computer and in Google Drive synchronized.

Last updated 2 November 2026

What the application does

Soltan Local Sync is a personal utility operated by Soltan Baghirli. It uses rclone on the owner’s computer to copy and synchronize files with the owner’s Google Drive account.

The current setup synchronizes selected folders in both directions, keeps backup copies of replaced files, and preserves separate versions when conflicting changes are detected. Depending on the configuration, changes can include uploads, downloads, updates, renames and deletions.

Why Google Drive access is needed

The utility needs to read file contents and metadata and to create, update, organize and delete files to perform synchronization. The Google authorization can cover the entire Drive account; the folders actually synchronized are determined by the local configuration.

The owner authorizes access through Google’s sign-in and consent flow. This website is an information page; it does not provide a sign-in form or access to Drive files.

Personal use and control

The application is intended for the operator’s own account and is not offered as a public file-storage service. The operator controls when it runs, which folders it synchronizes and when access is revoked.
