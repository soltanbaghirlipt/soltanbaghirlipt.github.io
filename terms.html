Intended use

The utility synchronizes selected folders between a local Windows computer and Google Drive using rclone. It is not a public file-hosting service, does not accept public registrations and does not promise continuous availability or third-party support.

Operation and file changes

Transfers depend on the computer, network connection, Google authorization and local configuration. Synchronization can copy, replace, rename or delete files. The operator is responsible for selecting the folders, reviewing conflicts and retaining appropriate backups.

The utility can be stopped locally, and its Google access can be revoked through Google Account settings. Existing files and backups must be managed separately.

Other services

Use of Google Drive, rclone, GitHub and any separately connected service remains subject to the relevant provider’s terms. Soltan Local Sync is an independently configured personal utility and is not an official Google, GitHub or OpenAI product.
